# X-chat

Мессенджер для Android: личная переписка, закрытые группы, отправка фото, файлов и голосовых сообщений.

## Как установить

1. Откройте раздел [«Релизы»](https://github.com/sergss/x-chat/releases).
2. Скачайте APK с окончанием `-release.apk` в названии.
3. Откройте скачанный файл на телефоне.
4. Если Android запросит разрешение на установку из этого источника, разрешите её и нажмите «Установить».
